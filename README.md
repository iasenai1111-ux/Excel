# Excel Quest — Nível 1 (Básico)

Jogo educacional para adolescentes: **5 fases sequenciais** de soma, subtração, multiplicação, média e porcentagem.

## Jogar

Abra `index.html` no navegador. No GitHub Pages, configure **Settings → Pages → Deploy from a branch → main / (root)**.

## Progressão

A fase seguinte só é desbloqueada quando o aluno:
1. coleta todas as moedas;
2. digita uma fórmula correta no terminal do jogo;
3. reproduz a fórmula no Excel real e marca a confirmação;
4. alcança a porta de saída.

O jogo **não verifica o arquivo do Excel**: a confirmação é declarada pelo aluno. O professor deve avaliar a planilha salva. A aba de cada fase vem no arquivo .xls que o botão do jogo gera (formato XML Spreadsheet 2003, aberto pelo Excel; pode solicitar confirmação de formato). Após abrir, o aluno pode escolher Salvar como .xlsx.

### Notas

- Movimentação: setas ou W A S D.
- Funciona offline; não usa serviços externos, contas ou macros.
- Reiniciar a fase limpa o progresso da fase. Não há persistência entre recarregamentos.
- Conteúdo pedagógico: fase 1 SOMA; 2 subtração; 3 multiplicação; 4 MÉDIA; 5 porcentagem.
