# 🎮 EXCEL QUEST — JOGAR AGORA

## ▶️ [CLIQUE AQUI PARA ABRIR O JOGO](https://iasenai1111-ux.github.io/Excel/)

**Link direto para alunos:** https://iasenai1111-ux.github.io/Excel/

### Como jogar e entregar

1. Digite **nome completo** e **turma** no jogo.
2. Baixe a planilha personalizada (formato Excel .xls compatível).
3. Abra no Excel e complete as 5 abas de prática, com fórmulas e instruções.
4. No jogo, recolha moedas, acerte a fórmula, confirme a prática e alcance a porta para abrir a próxima fase.
5. Salve o arquivo preenchido e envie pelo formulário indicado pelo professor.

### Entrega pelo Drive — configuração necessária

O botão **Entregar atividade** aparece no jogo, mas **não faz upload enquanto o formulário não for configurado**. Para ativar: crie um **Google Formulários** com perguntas obrigatórias de nome, turma e **upload de arquivo** (Excel). Em **Respostas**, vincule a uma planilha Google Sheets para acompanhar as entregas. Os arquivos serão armazenados no Drive do proprietário do formulário. O Google pode solicitar login aos alunos para upload. Não compartilhe credenciais ou tokens no repositório público.

Depois, no `index.html`, substitua `const DELIVERY_FORM_URL="";` pela URL pública **de resposta** do formulário, não a URL de edição. Isso habilita o botão. Recomenda-se usar um formulário da conta institucional do professor e informar aos alunos sobre o uso de dados pessoais para a atividade.

**Importante:** o jogo não verifica automaticamente as planilhas externas e não sabe quem entregou até o professor consultar as respostas do formulário.

### Conteúdo

Fases 1 a 5: soma, subtração, multiplicação, média, porcentagem. Todas sequenciais. Sem macros nem instalação.
